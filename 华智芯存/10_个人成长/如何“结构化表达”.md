最核心公式：
#### 结构化表达 = 结论 + 分类 + 逻辑 + 数据
S = C + F + L + D
核心思想：先结论，再展开。

最强基础公式：
PREP公式：先结论、有逻辑、有数据、有行动建议
`P → Point（结论）`
`R → Reason（原因）`
`E → Example（例子/数据）`
`P → Point（再次总结）`

最重要公式：
SCQA模型
`S → Situation（现状）`
`C → Complication（问题）`
`Q → Question（核心问题）`
`A → Answer（解决方案）`

MECE原则：“不重复，不遗漏”
将线性思维转为“树状思维”
