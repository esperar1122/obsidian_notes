1.安装LTP所需依赖
sudo apt install autoconf automake autotools-dev m4 gcc libssl-dev libaio-dev flex bison libcap-dev libregf-dev libdts-dev libdtools-ocaml-dev libnuma-dev libacl1-dev automake autoconf dma libmm-dev jfsutils libselinux1-dev xfslibs-dev netconfd numactl numad rpcbind nfs-kernel-server rsh-server sysstat
2.解压LTP源码包
tar -jxvf ltp-full-20200930.tar.bz2
cd ltp-full-20200930
4.如果是uos需要执行该步骤，kylin不需要执行：
（1）执行vim testcases/kernel/syscalls/ustat/ustat01.c编辑ustat01.c
在起始的头文件引用之前添加以下代码：
// 先屏蔽冲突的宏，避免头文件重复定义
#define _STATFS_H
#define _USTAT_H

// 显式包含需要的头文件，明确依赖顺序
#include <sys/types.h>
#include <sys/stat.h>
#include <sys/ustat.h>
#include <unistd.h>

// 再包含LTP的测试头文件
#include "../../../../include/tst_test.h"

// 恢复宏定义（如果后续需要）
#undef _STATFS_H
#undef _USTAT_H
（2）执行vim testcases/kernel/syscalls/ustat/ustat02.c编辑ustat02.c，添加内容同上
5.执行编译
make autotools
./configure
make -j8
sudo make install
4.执行测试
sudo /opt/ltp/runltp -p -l ~/ltp_result.log -d /tmp -o ~/ltp_output.log -t 48h
