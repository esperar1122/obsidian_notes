# 测试概述

## 基本信息
- **测试对象**：嘉合劲威U-DIMM内存模块
- **测试环境**：
  - 操作系统：Windows 10系统
  - 特殊说明：Memtest86 Pro通过UEFI环境直接执行，无需操作系统

## 测试目标与意义
- **测试目标**：全面验证U-DIMM内存模块的稳定性、兼容性和可靠性
- **测试意义**：确保内存产品在各种工作负载下能够稳定运行，提前发现潜在问题，保证产品质量

# 测试项目清单

## 可执行测试项目

### 1. Memtest86 Pro压力测试
- **测试时长**：持续12小时
- **测试目的**：从硬件层面全面检测内存稳定性，发现潜在的物理缺陷和电气故障
- **测试位置**：UEFI环境下直接运行

### 2. Passmark Rebooter循环测试
- **测试次数**：执行500次循环
- **测试目的**：验证系统在多次重启过程中的稳定性，特别关注内存初始化过程

### 3. Passmark Sleeper休眠测试
- **测试次数**：执行500次循环
- **测试目的**：测试系统在休眠/唤醒循环中的稳定性，检查内存数据保留情况

### 4. BurnInTest压力测试
- **测试时长**：持续8小时（480分钟）
- **测试目的**：进行全面的硬件压力测试，包括内存、CPU、磁盘等，模拟极端工作条件

### 5. SPD检查
- **测试时机**：必须在所有压力测试后进行
- **测试目的**：验证压力测试后内存参数配置是否正常，确保SPD中的内容未出现异常

## 暂时无法测试的项目

### 6. RST Pro压力测试
- **计划时长**：12小时
- **不可测试原因**：当前环境不支持
- **测试目的**：使用RST Pro工具进行内存压力测试，验证内存与存储系统的兼容性

### 7. 3DMark Time Spy压力测试
- **计划时长**：12小时
- **不可测试原因**：当前环境不支持
- **测试目的**：通过图形压力测试间接验证内存稳定性，特别是在高负载图形应用场景

# 测试软件安装与使用指南

## 1. Memtest86 Pro

### 工具概述
- **工具说明**：独立的内存测试工具，直接在UEFI/BIOS环境下运行，不依赖操作系统
- **测试功能**：执行多种内存测试算法，全面检测内存硬件故障、电气缺陷和时序问题

### 安装与使用步骤
1. 从测试工具文件夹获取`Memtest86.Pro.v11.5.1000.iso`镜像文件
2. 使用`Rufus`或`Etcher`等工具将ISO写入U盘，制作启动盘
3. 设置电脑从U盘启动，系统将自动进入Memtest86 Pro测试界面
4. 测试项目选择前13项，不选择第14项DMA测试，测试轮数选择100轮（暂定，确保测试时间达到12小时），语言修改为简体中文，并将配置保存
5. 测试将自动开始，持续运行12小时后记录结果

## 2. RST Pro

### 工具概述
- **工具说明**：Ram Stress Test Premium，用于测试内存的稳定性和性能
- **状态**：暂时无法测试
- **备注**：等待测试环境支持后再进行此测试

## 3. Passmark Rebooter

### 工具概述
- **工具说明**：Passmark公司开发的系统重启测试工具
- **测试功能**：通过多次自动重启系统，测试硬件在重启过程中的稳定性

### 安装与使用步骤
1. 解压测试工具文件夹中的`rebooter.zip`到本地目录
2. 右键点击`rebooter.exe`，选择「以管理员身份运行」
3. 在软件界面中进行如下设置：
   - 将循环次数修改为500次
   - 勾选「自动启动」选项
   - 输入测试系统的用户名和密码
   - 点击「自动登录」按钮开始测试
4. 测试将自动执行500次重启循环，完成后记录结果

## 4. Passmark Sleeper

### 工具概述
- **工具说明**：Passmark公司开发的系统休眠测试工具
- **测试功能**：通过多次自动休眠和唤醒系统，测试硬件在电源状态转换过程中的稳定性

### 安装与使用步骤
1. 解压测试工具文件夹中的`sleeper.zip`到本地目录
2. 右键点击`Sleeper.exe`，选择「以管理员身份运行」
3. 在软件界面中进行如下设置： 
   - 只勾选`S3 (Sleep 3)`和`S4 (Hibernate)`
   - 将循环次数修改为500次
4. 测试将自动执行500次休眠/唤醒循环，完成后记录结果

## 5. 3DMark

### 工具概述
- **工具说明**：专业的图形性能测试软件，包含Time Spy等多个测试场景
- **测试功能**：通过图形渲染压力测试，间接验证内存在高负载下的稳定性
- **状态**：暂时无法测试

### 安装步骤（供后续环境支持时参考）
1. 解压测试工具文件夹中的`3DMark-v2-32-8454.zip`到本地目录
2. 运行`3dmark-setup.exe`进行安装
3. 安装完成后，使用测试工具文件夹中`3DMark_key.txt`的内容激活软件
4. 运行软件，选择Time Spy测试场景，设置为压力测试模式，持续12小时

## 6. BurnInTest

### 工具概述
- **工具说明**：Passmark公司开发的全面硬件压力测试软件
- **测试功能**：同时测试内存、CPU、磁盘、图形等多个硬件组件，模拟极端工作负载

### 安装与使用步骤
1. 解压测试工具文件夹中的`PassMark.BurnInTest.Pro.9.0.Build.1011.rar`到本地目录
2. 运行`bitpro.exe`进行安装
3. 安装完成后，使用`key.txt`中的激活码进行软件激活
4. 双击运行BurnInTest，进行如下设置：
   - 使用默认测试用例配置
   - 将测试时长设置为480分钟（8小时）
   - 确保内存测试选项已启用
   - 点击「开始」按钮启动测试
5. 测试过程中保持环境通风良好，完成后记录测试结果

## 7. SPD检查工具

### 工具概述
- **工具说明**：华龙SPD烧录器，用于读取和验证内存模块SPD芯片中的参数信息
- **测试功能**：读取内存的制造商信息、时序参数、容量、频率等SPD数据，验证其完整性和正确性

### 使用方法
1. 确保在所有压力测试完成后进行此检查
2. 按照华龙SPD烧录器使用手册正确连接硬件设备
3. 运行SPD读取软件，获取内存模块的SPD参数
4. 核对读取的参数与内存规格是否一致，特别注意检查是否有异常数据
5. 记录检查结果，包括读取是否成功以及参数是否正常

# 测试注意事项

## 测试执行建议

### 1. 测试顺序
- 首先执行Memtest86 Pro压力测试（UEFI环境）
- 然后在Windows环境下依次执行：Rebooter循环测试 → Sleeper休眠测试 → BurnInTest压力测试
- 最后进行SPD检查，以验证压力测试后内存参数是否正常

### 2. 测试环境准备
- 测试期间保持环境通风良好，必要时使用额外散热设备
- 测试前清理系统，关闭不必要的应用程序和后台服务

### 3. 数据与系统安全
- 测试前备份测试环境中的所有重要数据
- 使用专用的测试系统，避免在生产环境或存储重要数据的系统上进行测试
- 长时间测试期间，确保系统有稳定的电源供应，建议使用UPS

## 测试记录与异常处理

### 1. 测试记录要点
创建标准化的测试记录表，包含以下信息：
- **测试基本信息**：
  - 测试时间：开始时间和结束时间
  - 测试环境：系统配置等
- **测试结果详情**：
  - 通过/失败状态
  - 错误信息（如有）
  - 观察到的现象：异常噪音、温度异常等

### 2. 异常情况处理流程

#### 系统崩溃或硬件异常
1. 立即停止当前测试
2. 记录详细的异常信息（错误代码、截图等）
3. 检查硬件连接是否正常
4. 确认异常是偶发性还是可重复性的
5. 必要时更换测试内存模块，对比测试结果
