> 易失性存储器：

- **SRAM-静态随机存储器**：由触发器存储数据，不需要刷新电路即可保存内部存储的数据，速度快且价格昂贵，cpu中的缓存就是SRAM；
- **DRAM-动态随机存储器**：由MOS管栅极电容存储数据，需要定时刷新电路解决电容漏电的问题，集成度高且容量大成本低；

> DRAM类型：	

- **SDR-同步动态随机处理器**：将DRAM和CPU通过相同时钟锁定，共享时钟周期，以相同速度同步工作；单倍数据速率存储数据，每根数据线每个时钟只传输1bit数据；
- **DDR-双数据率同步动态随机存储器**：允许在时钟脉冲上升沿和下降沿传输数据，不需要提高时钟频率就能加倍提高传输速度，比SDR多一倍的传输速率；

> IC位宽

```shell
# 核心概念与工作原理
> 位宽定义
   - IC位宽表示单个DRAM芯片一次可读写的数据位数。“4bit IC”即芯片每次操作处理4位数据（如0.5字节）
> DIMM模块的位宽扩展机制  
   - DIMM的整体数据通道固定为64位（满足CPU总线需求）
   - 单个4bit IC位宽不足时，需通过位方向扩展（Bit-Wise Extension）组合多个芯片：  
     - 示例：将16个4bit IC并联（位宽方向），可合成64位数据总线（16×4=64）
     - 扩展后，控制器通过行列地址（RAS/CAS）信号统一访问所有芯片，实现高效数据存取
> 实际应用场景  
   - 低功耗嵌入式系统（如IoT设备）常用4bit或8bit DRAM IC，因其成本低、体积小  
   - 但在标准DIMM中（如UDIMM/RDIMM），4bit IC需与其他芯片协同工作，无法独立提供完整内存功能
> 技术注意事项：
   - 性能影响：4bit IC的吞吐量较低（相比8bit或16bit），高频场景易成瓶颈，需优化时序（如tRCD/tRP参数）
   - 兼容性校验：设计时需确保所有并联芯片的时序一致，避免数据冲突（通过SPD信息验证）
```

> DIMM相关组成概念

```shell
内存控制器（存在于CPU）-> channel（内存通道）-> DIMM -> Rank -> DRAM Chip -> BankGroup -> Bank -> 存储阵列（Row/Column）-> cell（基本存储单元）

# 单个cell组成：栅极晶体管 + 电容器，充电状态存储1，放电状态存储0；
# 存储阵列：通过bitline + wordline组成Row/Column，wordline连接行地址缓冲区和行地址解码器，感应（差分）放大器两端分别连接两条独立bitline，感应放大器通过多路复用器连接突发缓冲区，实现突发传输；
# BankGroup + Bank：实现内存交织，进行更细粒度的并行访问，大大提高了并发访问效率；
# Rank: 多个DRAM拼接，实现64bits传输；
# DIMM：一个DIMM存在1个或多个Rank；
# 内存通道：地址总线 + 指令与控制总线 + 数据总线；
# 内存控制器：内存控制器数量决定channel数量，实现CPU和内存交互，其核心功能包括地址解码、时序控制和数据缓冲；
```

> DIMM类型及区别

```shell
# SODIMM（小型双列直插内存模块）
- 全称：Small Outline Dual In-line Memory Module
- 定义：专为空间受限设备设计的紧凑型内存模块，采用集成电路的计算机存储器
- 特点：
  - 体积比标准DIMM小约50%，引脚更密集
  - DDR3L(低电压版)功耗降低15%，兼容1.5V/1.35V双模式
  - 容量和频率通常比台式机内存条低
- 主要用途：笔记本电脑、迷你主机、一体机等便携设备
# UDIMM（无缓冲双列直插内存模块）
- 全称：Unbuffered Dual In-line Memory Module
- 定义：地址和控制信号不经缓冲器，直接到达DIMM上的DRAM芯片的内存模块
- 特点：
  - 同频率下延迟较小，因为没有寄存器缓冲
  - 容量和频率较低，单条容量通常2GB/4GB，最高主频约1.33GHz
  - 价格相对低廉
- 主要用途：消费级PC和部分预算有限的服务器应用
# RDIMM（带寄存器的双列直插内存模块）
- 全称：Registered Dual In-line Memory Module
- 定义：在DRAM模块与内存控制器之间增加寄存器的内存模块
- 特点：
  - 通过板载寄存器(DB)和时钟驱动芯片(RCD)提升信号稳定性及内存容量
  - 单条容量在2～32GB之间，频率有1.33GHz和1.6GHz两种选择
  - 相比UDIMM，容量和频率更容易提高
- 主要用途：服务器、数据中心和高效能工作站
# LRDIMM（低负载双列直插内存模块）
- 全称：Load-Reduced Dual In-line Memory Module
- 定义：使用iMB(isolation Memory Buffer)缓冲芯片替代传统Register芯片的内存技术
- 特点：
  - 显著降低内存总线的电气负载和功耗
  - 支持更大内存容量，提升总线频率
  - 相比RDIMM，缓冲降低了下层主板上的电力负载，但对内存性能几乎无影响
- 主要用途：专为高密度内存需求的服务器设计
```

> DIMM相关计算

```shell
# 外部时钟频率（MHz）：物理时钟信号的实际频率
# 数据传输率（MT/s）：逻辑层面的传输速率
- DDR：
外部时钟频率（MHz）= 数据传输率（MT/s）/ 2
- SDR：
外部时钟频率（MHz）= 数据传输率（MT/s）
# 内部时钟频率（MHz）：内部核心频率，需结合预取位（Prefetch）扩展，预取位和等效位不一致时采用等效位
内部时钟频率（MHz）= 数据传输率（MT/s）/ 预取位（bit）
# 带宽计算
带宽（GB/s）= 数据传输率（MT/s）* 位宽（bit）/ 8 / 1024，其中位宽通常为64位
```

> 内存寻址

```shell
# 内存控制器作为CPU与内存之间的桥梁，负责管理内存的读写操作。其核心功能包括地址解码、时序控制和数据缓冲。当CPU需要访问内存时，内存控制器通过地址总线将地址信号传输到内存模块；
- 地址发送：
地址总线将生成的地址信号传输给内存控制器
地址总线位数决定了系统可寻址的内存空间大小
- 地址解码：
内存控制器接收到地址后，进行解码以确定要访问的具体内存单元 -> 通过页表将逻辑地址转化为物理地址
- 数据访问：
解码完成后，内存控制器根据控制信号执行读取或写入操作
读取时数据通过数据总线返回CPU，写入时数据通过数据总线传输到指定地址

#地址信号解码：31位地址信号，其中27位用于寻址，剩余4位地址信号用于其他控制功能，可能包括Bank激活控制、刷新控制等
- BankGroup选择：前3位地址信号选择对应的BankGroup
- Bank选择：后续2位选择指定Bank
- Row Address：后续13位（8192行）通过行地址解码器解码用于行寻址
- Column Address：后续9位（512列）通过列地址解码器用于列寻址
```

> 内存读/写、刷新操作

```shell
# 读过程：
- 首先将所有wordline置为低电平，所有晶体管不导通；
- 再将所有bitline进行预充电至高电位的1/2；
- bitline预充电完成后，将指定wordline置为高电平，使指定行的晶体管导通；
- 感应放大器放大指定行上每个点位的电位变化，并锁存该行所有点位存储的值；
- 通过数据缓冲区将锁存的值传输给数据总线；

# 写过程：
写操作之前先进行刷新操作，通过感应放大器锁存其它bitline的值，再通过列地址给指定bitline上施加对应的电平，实现数据更新；
- 写入0：将指定bitline的电位从1/2拉低，感应放大器感应电位变化将指定bitline的电容器放电到0，再将指定wordline置为低电平关闭晶体管；
- 写入1：将指定bitline的电位从1/2拉高，感应放大器感应电位变化将指定bitline的电容器充电到1，再将指定wordline置为低电平关闭晶体管；

#刷新操作：
- 在retention时间周期内必须刷新一次wordline上所有值，保证数据不丢失，其实就是先读取再写入；
- 刷新操作命令由内存控制器发出，内存自行完成刷新；所谓读取写入就是将bitline预充电至高电位的1/2，实现电容器和感应放大器的值同步；
```

> 内存交织

```shell
# 内存交织通过（并行访问内存模块）来减少延迟。其核心思想是将连续的内存地址交替映射到不同的BankGroup的不同Bank中，使得系统可以同时或流水线式地访问多个Bank，从而最大化利用内存带宽；每个Bank都是一个独立的存储阵列，拥有自己的行缓冲器和控制电路。这种多Bank设计为内存交织提供了硬件基础；
# DRAM中的Bank交错访问通过以下方式实现：
- 地址映射策略：内存控制器使用地址的低位(如最低2-3位)决定Bank分配，确保相邻地址落在不同Bank中
- 独立操作时序：每个Bank可以处于激活、预充电或数据传输等不同阶段
- 流水线调度：当一个Bank完成数据突发传输时，下一个Bank已经准备好开始传输
# 典型的内存交织操作流程
- 地址解码阶段：控制器解析请求地址，确定目标Bank和行/列
- Bank激活阶段：目标Bank的行被激活，数据加载到行缓冲器
- 数据传输阶段：从行缓冲器突发传输多个数据单元
- 预充电阶段：当前Bank完成传输后开始预充电，同时其他Bank已开始新操作
```

> 突发传输

```shell
# 突发传输的核心机制
1. 行激活阶段：
   - 发送行地址和激活命令(RAS)
   - 整行数据加载到行缓冲器(tRCD延迟)
2. 列选择阶段：
   - 发送起始列地址和读/写命令(CAS)
   - 指定突发长度(Burst Length, BL)
3. 数据传输阶段：
   - 从行缓冲器连续输出BL个数据单元
   - 列地址自动递增，无需重复发送CAS
# 突发传输通过以下方式提升DRAM性能：
- 带宽利用率：单次列地址访问多个数据单元
- 命令效率：减少重复发送列地址的开销
- 时序优化：重叠不同Bank的操作隐藏延迟
```

> 数据预取（prefetch）

```shell
# 工作原理：
在DRAM多Bank环境中，预取技术通过Bank级并行性显著提升了效率：

- 并行预取通道：每个Bank可以作为一个独立的预取通道，同时预取不同地址范围的数据
- 重叠操作：当一个Bank正在执行行激活或数据准备时，其他Bank可以同时进行预取操作，有效隐藏内存延迟
- 预取调度：内存控制器根据Bank状态和访问模式，智能调度各Bank的预取顺序和时间

# 典型预取流程
- 模式检测阶段：控制器监测内存访问流，识别顺序访问、跨步访问等可预测模式
- Bank选择阶段：根据预测的访问地址，确定目标Bank并检查其可用状态
- 预取执行阶段：
   - 激活目标Bank的行(Row Activation)
   - 将行数据加载到该Bank的行缓冲器
   - 保持行开放状态以备后续快速访问
- 数据利用阶段：当处理器实际需要该数据时，直接从行缓冲器快速获取，避免完整的内存访问延迟。
```
