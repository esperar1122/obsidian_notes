# DRAM Bank中的突发传输机制详解

## DRAM Bank基本结构与工作原理

DRAM采用多Bank并行架构，每个Bank是一个独立的存储阵列，包含以下核心组件：

1. **存储阵列**：由行列排列的存储单元(cell)组成，每个单元通过电容存储数据
2. **行缓冲器(Row Buffer)**：临时存储从存储阵列读取的整行数据
3. **传感放大器(Sense Amplifier)**：放大微弱的电容信号并恢复数据
4. **输出缓存(Output Buffer)**：暂存准备输出的数据

当指定行地址的行被激活时，会发生以下操作：
1. 行地址解码器选择目标行
2. 整行数据(通常4KB-8KB)被传送到传感放大器
3. 传感放大器放大信号并将数据锁存到行缓冲器
4. 行缓冲器保持数据直到预充电命令发出

## 突发传输的核心机制

突发传输(Burst Transfer)是DRAM高效数据传输的关键技术，其工作流程如下：

1. **行激活阶段**：
   - 发送行地址和激活命令(RAS)
   - 整行数据加载到行缓冲器(tRCD延迟)

2. **列选择阶段**：
   - 发送起始列地址和读/写命令(CAS)
   - 指定突发长度(Burst Length, BL)

3. **数据传输阶段**：
   - 从行缓冲器连续输出BL个数据单元
   - 列地址自动递增，无需重复发送CAS

### 突发传输的关键参数

| 参数         | 描述                   | 典型值(DDR4) |
| ------------ | ---------------------- | ------------ |
| 突发长度(BL) | 连续传输的数据单元数量 | 8            |
| tRCD         | 行激活到列访问的延迟   | 15-20ns      |
| CAS延迟      | 列地址到数据输出的延迟 | 14-16周期    |
| 预取深度     | 每个周期预取的数据量   | 8n           |

## 数据路径与多路复用机制

数据从存储阵列到输出缓存的传输路径涉及复杂的多路复用：

1. **行缓冲器到输出缓存路径**：
   - 列解码器选择行缓冲器中的特定列
   - 多路复用器(MUX)将选中的数据传输到全局I/O线
   - 数据通过串行化电路转换为高速串行流

2. **多Bank并行机制**：
   - 多个Bank可同时进行行激活和突发传输
   - 交错访问不同Bank可隐藏预充电延迟
   - Bank Group设计(DDR4+)提供额外并行层次

## 不同DRAM标准的突发传输实现

### DDR3/DDR4/DDR5关键差异

| 特性       | DDR3         | DDR4          | DDR5          |
| ---------- | ------------ | ------------- | ------------- |
| 预取架构   | 8n           | 8n            | 16n           |
| 突发长度   | 4/8          | 8             | 16            |
| Bank Group | 无           | 4组           | 8组           |
| 数据速率   | 800-2133MT/s | 2133-4266MT/s | 4800-7200MT/s |
| 电压       | 1.5V         | 1.2V          | 1.1V          |

DDR5的主要改进：
1. 双通道设计：每个DIMM提供两个独立32位通道
2. 更长的突发长度(BL16)提升带宽利用率
3. 更高的Bank并行度(8 Bank Groups)

## 性能优化与应用

突发传输通过以下方式提升DRAM性能：
1. **带宽利用率**：单次列地址访问多个数据单元
2. **命令效率**：减少重复发送列地址的开销
3. **时序优化**：重叠不同Bank的操作隐藏延迟

典型应用场景：
1. 顺序内存访问(如数组遍历)
2. 缓存行填充
3. 媒体数据处理(视频/音频流)

现代DRAM控制器通过智能调度算法优化突发传输：
1. 基于访问模式的Bank交错调度
2. 自适应预充电策略
3. 优先级感知的请求重排序
