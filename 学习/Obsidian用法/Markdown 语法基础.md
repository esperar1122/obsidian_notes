## 1、标题：    

()#一级标题（最大）           
  ##二级标题      
  ###三级标题    
  ####四级标题    
  #####五级标题    
  ######六级标题(最小)    
## 2、文本样式：    

斜体：`*` 或 `_` 包裹                        *斜体文字*  或 _斜体文字_    快捷键Ctrl + I    
粗体：`** **` 或 `__  __` 包裹         **粗体文字** 或 **粗体文字**    快捷键Ctrl + B    
斜体 + 粗体：`***` 或 `___` 包裹       ***斜体加粗文本***    
删除线：`~~` 包裹                             ~~删除的文本~~    
高亮（部分编辑器支持）：` == ` 包裹  ==高亮文本==    

## 3、列表：    

- 无序列表：`-` / `*` / `+` 加空格开头  
1. 有序列表： `数字.` 加空格开头        
- [ ] 未完成任务 `- [ ]`                快捷键 ctrl + L
- [×] ~~已完成任务~~ `- [×]`                快捷键 ctrl + L 按两次

## 4、链接与图片（Links & Images）    

- 外部链接：`[显示文本](链接地址 "提示文字")`
例： [百度](https://www.baidu.com  "点击访问")
- 图片： `![替代文本](图片地址 "提示文字")` (比链接多一个 `!`)
例：[示例图](https://seopic.699pic.com/photo/50118/7084.jpg_wh1200.jpg "点击这里")
- 内部双链（Obsidian专属）：`[[目标笔记名]]`
例：[[Markdown 语法基础]]    
## 5、代码（Code）    

- 行内代码：反引号 `` ` `` 包裹
 这是行内代码：`print("Hello World!")`    
- 代码块：三个反引号`` ``` ``包裹，可指定语言：反引号后面加 "编程语言"
```python
def hello():    
	print("Hello World!")    
```
```c++
def hello():  
	printf("Hello World!");  
```

## 6、引用（Blockquotes）

用 `>` 开头，可嵌套：
>这是一级引用
>> 这是嵌套的二级引用 `>>`

## 7、表格（Tables）

用`|` 分隔列， `-` 分隔表头和内容:

| 左对齐 | 居中对齐 | 右对齐 |
| :-- | :--: | --: |
| 内容1 | 内容2  | 内容3 |
| 内容4 | 内容5  | 内容6 |

## 8、分割线(Horizontal Rules)

单独一行用 `---` / `***` / `___` （三个及以上符号）:

---
或
***
或
___

## 9、实用小技巧

- 换行：段落末尾加 两个空格 再回车，或直接空一行  
- 转义字符：想显示 `*` 、 `[` 等符号，在前面加 `\` , 比如 `\*` → `*`    \* \[
- 编辑器快捷键：Obsidian中常用语法有快捷键，按`Ctrl + P`查看
