### NUMA：非一致性内存访问

核心概念：在早期的多路服务器中，所有CPU共享一条总线访问同一块内存，这被称为 **UMA** （一致性内存访问）。但随着CPU核心数激增，这条独木桥变得极其拥堵，性能大幅下降。

核心目的：解决多CPU扩展性，降低物理延迟

**NUMA** 应运而生。它的核心思想是：“**就近原则**”
- 系统将CPU和一部分内存划分位一个节点Node
- 本地访问：CPU访问自己节点内的内存，速度极快，延迟最低。
- 远程访问：CPU访问其他节点的内存，速度较慢，延迟较高

在NUMA架构下，跨节点访问内存的延迟可能是本地访问的3.5倍，带宽可能只有本地的45%

适用场景：多路服务器、现代多核 CPU

查看 NUMA 拓扑：numactl --hardware
### 内存交织：一种分配策略

内存交织是一种将数据分散存储的技术，旨在提高内存带宽利用率。在NUMA语境下，它通常指 **交错分配策略** 。

核心目的：平衡各节点带宽，避免内存热点

模式：
想象有两个水桶(Node 0 和 Node 1的内存)。
- 默认模式（本地优先）：程序会先把Node 0 的水桶装满，再装 Node 1.如果程序只用Node 0的 CPU，那 Node 1 的带宽就浪费了；如果程序跨节点跑，Node 0 的总线就堵死了。
- 交织模式：就像发扑克牌一样，第一张牌给 Node 0，第二张给 Node 1，第三张给 Node 0....数据被均匀地打散再所有节点的内存中。

作用：
- 负载均衡：确保所有内存通道的带宽都被利用起来，避免某个节点内存耗尽而另一个节点闲置。
- 代价：虽然带宽利用率最高，但CPU访问任何数据都有概念变成“远程访问”（数据被打散了），导致平均延迟略微上升。

适用场景：
数据库、高性能计算、需要大内存的应用

开启内存交织：numactl --interleave=all mysqld #让mysqld进程在所有节点上交错分配内存
绑定CPU和内存（NUMA亲和性）：追求极致低延迟，可以把进程绑定在特定节点，只访问本地内存：
numactl --cpunodebind=0 --membind=0 ./my_app #将进程绑定在节点0的CPU和内存上

### EMC

#### 什么是EMC？

EMC 即，Electromagnetic Compatibility（电磁兼容性），通俗来说，就是电子设备之间“和平共处”的能力——既能自身稳定运行，不向外释放过量的电磁干扰，也能在周边复杂的电磁环境中，抵御外界干扰，保持功能正常。EMC测试就是对这种能力进行科学检测与评定，是量化设备电磁性能、保障产品可靠性与合规性的关键流程。

EMC测试的核心目的包含两个层面，二者相辅相成、缺一不可
- EMI，限制设备自身的电磁干扰，避免其成为“干扰源”，影响周边设备、电网及环境；
- EMS，验证设备的电磁抗扰度，确保其不会被外界电磁干扰影响，在复杂环境中依然能稳定发挥功能。

EMC测试项目：
- ESD：模拟人体或物体接触设备时产生的静电干扰。接触放电通常为±8kV，空气放电为±15kV
- Surge浪涌：模拟雷击、大电流开关引起的瞬时浪涌冲击。±1kV~±4kV
- RE辐射发射：主要检测设备通过“空间路径”，向外辐射的电磁波强度。30MHz~6GHz
- CE传导发射：主要检测设备通过电源线、信号线等“有线路径”，传导到电网或其他连接设备的电磁噪声。150kHz~30MHz
- RS辐射抗扰度：模拟周边无线设备产生的射频电磁场干扰，测试频率范围为80MHz~6GHz
- CS传导抗扰度：模拟通过电源线、信号线传入设备的射频干扰，150KHz~80MHz。
